# SolidWorks 单零件二维工程图

## 目标与范围

仅处理已完成设计的 `.SLDPRT` 单零件。创建与指定零件、配置和显示状态保持关联的 `.SLDDRW`，并按需导出 PDF、DWG 或 DXF。将图纸作为制造、装配和检验依据，确保表达完整、清楚、唯一且可执行。

不要重建或改变三维几何，不要根据照片、截图或实物反推正式制造尺寸，不要把装配体工程图或独立手工二维绘图混入本流程。

## 不可违反的执行边界

1. 必须使用“上海加速纪元图框”模板及其图纸格式、字体和标题栏规范。
2. 只通过 SolidWorks 原生 COM API、宏接口或等效原生自动化接口打开、重建、建图、创建或修改视图、建立投影关系、导入或整理尺寸、填写标题栏、保存和导出。
3. 禁止使用远程桌面、鼠标点击、键盘模拟、屏幕坐标、截图识别或图像识别创建、修改、标注、排版、保存或导出工程图。
4. 原生接口无响应、不可调用或被对话框阻塞时，停止并报告；不得切换到 UI 自动化继续，也不得宣称已经完成。
5. 允许渲染已经导出的页面做只读复核；不得用图像反推正式制造尺寸或驱动 SolidWorks 界面操作。
6. 公差、配合、基准、形位公差、粗糙度、材料状态、热处理、硬度、涂层和其他制造要求必须有受控工程来源，不得依据软件默认值、经验或外观补定。
7. 所有基本视图必须由主视图生成并保留正式投影对齐；所有视图、尺寸和注释必须保持模型关联。
8. 必须按完整文字、箭头、尺寸线和引出线的实际显示包围框执行有效图框四边检查，不能只检查插入点、锚点或视图轮廓。
9. 发现导出文件存在问题时，必须返回 `.SLDDRW` 修正并重新导出；严禁直接修改 PDF、DWG 或 DXF 掩盖源工程图问题。

开始前先读取 [reference-map.md](references/reference-map.md)，并根据以下步骤加载指定规则。不要用本文件的流程摘要替代详细参考资料。

## 工作流程

### 第一步：确认模型并建立关联工程图

1. 完整读取 [solidworks-single-part-workflow.md](references/general/solidworks-single-part-workflow.md)。
2. 打开原始 `.SLDPRT`，确认对象为单零件，核对版本、配置、显示状态、单位、材料和模型重建状态。
3. 读取模型属性、已有尺寸、PMI、关键配合与功能面，并区分模型驱动信息、经批准要求和实体测量参考值。
4. 使用上海加速纪元模板选择图幅和图纸格式，从指定零件、配置和显示状态建立关联主视图。
5. 保留原模型，不为出图或标注方便修改几何。

### 第二步：判断零件类别并确定视图方案
==
1. 完整读取 [part-classification.md](references/general/part-classification.md) 和 [view-selection-and-linework.md](references/general/view-selection-and-linework.md)。
2. 判断零件的主类别；同时符合多个类别时，以加工和标注特征最突出的类别为主类别，其余作为次类别。
3. 按 [reference-map.md](references/reference-map.md) 读取主类别及显著次类别的 Markdown 规则；需要确认推荐视图示意时一并检查对应 JPG 或 PNG。
4. 选择最能表达工作位置、主要形状或主要加工位置的主视方向，由主视图生成所需基本投影视图。
5. 按类别规则决定是否增加等轴测、剖视、断面、局部、斜视或放大视图，并建立中心线、中心标记和正式投影对齐。
6. 按 [view-selection-and-linework.md](references/general/view-selection-and-linework.md) 设置比例、可见线、隐藏线、切线边、中心线、剖面线和显示样式。

### 第三步：逐特征分析、标注并完成图纸信息

1. 完整读取 [general-dimensioning-rules.md](references/general/general-dimensioning-rules.md)。
2. 按模型顺序建立实体外形、孔、孔组、槽、台阶、螺纹、倒角、圆角、阵列及其他特征清单。
3. 按 [reference-map.md](references/reference-map.md) 为每种实际存在的特征读取对应 Markdown 规则，不得只凭通用规则标注特殊结构。
4. 为每个特征检查定形、定位和总体尺寸，优先导入并整理模型尺寸或 PMI，消除遗漏、重复、矛盾和无意封闭尺寸链。
5. 仅在有可靠来源时补充公差、配合、基准、形位公差、粗糙度、热处理、表面处理及未注要求。
6. 源模型没有可导入尺寸或 PMI 时，严格按 [general-dimensioning-rules.md](references/general/general-dimensioning-rules.md) 和 [solidworks-single-part-workflow.md](references/general/solidworks-single-part-workflow.md) 执行测量参考标注，不得把测量值升级为正式制造要求。
7. 按通用规则填写标题栏、材料、比例、单位、图号、名称、版本和技术要求，并按实际显示包围框整理视图、尺寸与注释。

### 第四步：修改审核、导出与复核

1. 完整读取 [final-review-checklist.md](references/general/final-review-checklist.md)。
2. 强制重建模型和工程图，确认模型引用、配置、显示状态、材料、视图、尺寸和注释均正确关联且没有悬空或丢失引用。
3. 对模型中的每个面、孔、槽、台阶、螺纹、倒角和圆角执行逐特征覆盖检查。
4. 按审核清单检查视图、投影、剖视、图线、尺寸完整性、孔组、螺纹、标准结构、标题栏和文件版本。
5. 使用原生接口获取尺寸、孔标注、符号、引出注释、技术要求和标题栏文字的实际显示包围框，执行有效图框四边、安全间距、重叠和遮挡检查。
6. 保存 `.SLDDRW`，通过原生接口导出所需 PDF、DWG 或 DXF，并渲染全部页面做只读视觉复核。
7. 发现越界、遮挡、缺失或显示异常时，返回第三步或工程图源文件修正，重新重建、审核和导出，直至全部通过。

## 条件分支

- 无法确定零件类别时，同时读取最接近的类别规则，并以加工、装配和检验特征确定主类别。
- 零件包含多个类别的显著结构时，读取主类别和所有相关次类别规则。
- 模型包含孔、孔组、螺纹、槽、齿形、钣金、铸造或其他专用特征时，读取对应特征规则。
- [deferred-tolerancing-rules.md](references/general/deferred-tolerancing-rules.md) 默认不作为正式出图依据；只有用户明确启用或任务是审阅该文档时才读取。即使启用，制造要求仍必须具有受控来源。
- 任一强制条件无法满足时，报告阻塞项、已完成范围、未验证内容和所需输入，不得以“基本完成”代替合格交付。

## 合格交付条件

- `.SLDDRW` 关联正确模型、配置、显示状态和材料，并已成功强制重建。
- 视图足够但不冗余，基本视图具有正式投影关系，剖视、断面和局部图来自当前模型。
- 每个制造、装配和检验特征均有完整且唯一的定义，没有遗漏、重复、矛盾或无意封闭尺寸链。
- 所有制造要求具有可靠来源；测量参考尺寸没有被误作批准制造尺寸。
- 所有标注和标题栏内容通过实际包围框、有效图框四边、安全间距、重叠与遮挡检查。
- 源工程图和全部导出页面均已复核，任何问题都已在 `.SLDDRW` 中修正并重新导出。
