# 暂不默认启用的公差与表面要求规则

十七、基准和形位公差

1. 基准选择
   基准A通常选主要安装、支承或定位面；基准B、C用于限制其余自由度。轴类可用中心轴线作为基准，盘类常用端面加中心轴线。

2. 形状公差
   直线度、平面度、圆度、圆柱度控制单一要素本身，一般不需要引用基准。

3. 方向公差
   平行度、垂直度、倾斜度必须相对基准表达。

4. 位置公差
   位置度、同轴/同心关系、对称度等用于控制特征相对基准的位置。孔组位置度应与理论正确尺寸配合。

5. 跳动和轮廓度
   圆跳动、全跳动适合控制回转表面相对基准轴线的综合误差；线轮廓度、面轮廓度用于控制复杂轮廓。

注意事项：
1. 基准次序应符合装配定位顺序和实际检验装夹方式。
2. 公差框格应指向正确的被控要素，不得含糊地附在无关尺寸或中心线上。
3. 尺寸公差和形位公差要共同满足功能，避免重复、冲突或无法检测。
4. 最大实体、最小实体、自由状态、公共公差带等修饰符只能在设计明确需要时使用。


十八、尺寸公差、配合和表面要求

1. 尺寸公差
   关键尺寸可采用上下偏差、对称公差、极限尺寸或公差带代号；选择形式应便于制造和检验。

2. 孔轴配合
   零件图按生产要求标孔或轴的公差带/偏差；配合制度、配合性质和公差等级必须来自设计。

3. 表面粗糙度
   在对应表面或尺寸界线上标注；相同要求可统一说明，功能面、配合面和密封面应单独确认。

4. 热处理和表面处理
   明确处理类型、范围、硬度/层深或涂层厚度等要求，并说明处理前后哪些尺寸为最终验收尺寸。

注意事项：
1. 不要给所有尺寸机械地添加同一公差。
2. 粗糙度越小不等于设计越好，应按功能和工艺选择，并须有批准依据。
3. 局部热处理、局部镀覆或禁止处理区域必须用视图、引出线或范围尺寸明确。
