# 轴类零件


典型零件：
传动轴、阶梯轴、主轴、销轴、偏心轴、花键轴、齿轮轴、活塞杆。

分类特征：
1. 以一条长轴线为主要结构中心。
2. 长度通常明显大于最大直径。
3. 主要结构由同轴或偏心圆柱、圆锥和轴肩组成。

推荐视图：
1. 轴线水平的主视图。
2. 键槽、扁位、花键或非圆截面增加端视图或断面图。
3. 退刀槽、中心孔、小圆角等可增加局部放大图。
4. 轴向孔、交叉油孔复杂时增加剖视或局部剖视。

必须检查的几何尺寸：
1. 总长度。
2. 各轴段直径及长度。
3. 轴肩位置、轴肩高度和端面位置。
4. 圆锥段的大端直径、小端直径、锥度或角度及长度。
5. 键槽宽度、深度、长度和轴向位置。
6. 花键或齿形的标准规格和有效长度。
7. 螺纹规格、旋向、有效长度及退刀槽。
8. 卡簧槽、密封槽、越程槽的槽宽、槽底直径和位置。
9. 横孔、径向孔、轴向孔的孔径、数量、深度和位置。
10. 中心孔规格。
11. 倒角、圆角和过渡圆弧。

有设计依据时检查的精度项目：
1. 配合轴颈的尺寸公差和配合代号。
2. 各轴颈相对主要基准轴线的同轴度或圆跳动。
3. 轴肩端面对基准轴线的垂直度或端面跳动。
4. 重要轴颈的圆度、圆柱度和直线度。
5. 键槽相对轴线或中心平面的对称度、位置度。
6. 配合面、密封面和轴承位的表面粗糙度。

标注排布：
1. 直径尺寸集中布置在轴的上方或下方。
2. 轴向长度按同一基准集中布置。
3. 小段长度靠近轮廓，总长度放在最外侧。
4. 避免形成无意的封闭轴向尺寸链。
