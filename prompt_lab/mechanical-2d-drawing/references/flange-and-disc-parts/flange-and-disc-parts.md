# 法兰与盘盖类零件

典型零件：
法兰、端盖、轴承盖、压盖、圆盘、轮毂盘、圆形安装座。

分类特征：
1. 以回转轴线为结构中心。
2. 外径通常明显大于轴向厚度。
3. 常具有中心孔、止口、台阶、圆周孔组或密封槽。

推荐视图：
1. 圆形主视图。
2. 通过回转轴线的轴向全剖视图或半剖视图。
3. 等轴测图。
4. 局部槽、密封结构不清楚时增加局部放大图。

圆形视图必须检查：
1. 安装孔直径。
2. 安装孔数量。
3. 螺栓孔分布圆直径。
4. 孔组的均布、角度或坐标定位关系。
5. 径向槽、缺口、耳板及异形孔尺寸。
6. 孔中心标记及水平、垂直中心线。
7. 典型孔组写法：“n×⌀d 均布于 ⌀D”。

轴向剖视图必须检查：
1. 法兰外径。
2. 中心孔、台阶孔、止口和凸台直径。
3. 法兰总厚度。
4. 各台阶高度或深度。
5. 沉孔、锪孔和螺纹孔深度。
6. 密封槽的宽度、深度和位置。
7. 密封面宽度。
8. 倒角、圆角和槽底半径。

有设计依据时检查的精度项目：
1. 中心孔、止口的尺寸公差和配合。
2. 孔组相对中心轴线的位置度。
3. 安装端面或密封面的平面度。
4. 安装端面对中心轴线的垂直度或端面跳动。
5. 外圆、中心孔和止口的同轴度或圆跳动。
6. 两端面的平行度。
7. 密封面、止口和配合孔的粗糙度。

标注排布：
1. 圆形主视图主要标孔组、分布圆和径向槽。
2. 同轴外径、内径和台阶直径集中标在轴向剖视图。
3. 剖视图中的直径由小到大向外嵌套排列。
4. 轴向尺寸集中放在剖视图一侧，总厚度置于最外侧。
5. 倒角可放在右上方，圆角和槽底半径可放在下方或右下方。
6. 主视图与剖视图之间不得重复标注同一外径、孔径或厚度。
