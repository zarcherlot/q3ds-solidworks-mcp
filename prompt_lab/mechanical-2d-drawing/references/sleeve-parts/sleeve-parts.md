# 套筒类零件

典型零件：
轴套、衬套、导套、隔套、缸套、带法兰轴套。

分类特征：
1. 内外表面以同轴圆柱面为主。
2. 具有明显内孔，主要功能为支承、导向、隔离或配合。

推荐视图：
1. 轴线水平的轴向全剖视图。
2. 有径向孔、缺口或非回转结构时增加端视图。
3. 油槽和局部结构可增加断面图或局部放大图。

必须检查的几何尺寸：
1. 内径、外径和总长度。
2. 各段内外径及轴向长度。
3. 台阶、挡肩和法兰尺寸。
4. 壁厚；若已由内外径完整确定且壁厚不是控制尺寸，则不重复标注。
5. 油槽、密封槽、卡槽的槽宽、槽深和位置。
6. 径向孔、油孔的孔径、数量和位置。
7. 缺口、止动槽和开口方向。
8. 倒角和圆角。

有设计依据时检查的精度项目：
1. 内孔和外圆的尺寸公差与配合。
2. 内孔与外圆的同轴度。
3. 内孔或外圆的圆柱度。
4. 端面对孔轴线的垂直度。
5. 两端面的平行度。
6. 滑动面、配合面和密封面的粗糙度。
