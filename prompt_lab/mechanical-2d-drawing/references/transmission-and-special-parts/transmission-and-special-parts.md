# 传动与异型类零件

典型零件：
齿轮、齿条、蜗轮、蜗杆、链轮、带轮、凸轮、摩擦轮。

分类特征：
1. 具有齿形、带槽、链齿、凸轮曲线或摩擦工作面。
2. 除普通结构尺寸外，还需要专用参数和精度要求。

普通结构尺寸：
1. 基准孔、轴颈和轮毂尺寸。
2. 键槽、花键和连接孔尺寸。
3. 齿宽、轮缘宽度、轮毂长度和总体宽度。
4. 端面、倒角、圆角、退刀槽和工艺孔。

齿轮、蜗轮、蜗杆需要确认的专用参数：
1. 模数、齿数、压力角。
2. 螺旋角、旋向和变位系数。
3. 精度等级及齿厚或检验参数。
4. 分度圆、齿顶圆等必要参数。
5. 齿面热处理、硬度和粗糙度。

链轮、带轮需要确认的专用参数：
1. 链条或带的规格。
2. 齿数、槽数、节距和节圆。
3. 槽宽、槽深和槽角。
4. 径向跳动和端面跳动。

凸轮需要确认的专用参数：
1. 基圆、行程和运动角。
2. 理论轮廓、实际轮廓和滚子尺寸。
3. 运动规律、旋向和起始位置。
4. 轮廓度及工作面粗糙度。

注意事项：
专用参数不能只根据三维外形推测，必须从设计参数、模型属性、计算文件或用户输入中获取。
