# 斜面、锥面、曲面与偏心结构标注


1. 斜面
   标注角度、斜面起止位置及必要的线性尺寸。倾斜表面在基本视图中失真时，使用斜视图显示实形。

2. 锥面
   可采用大/小端直径与长度、锥角，或锥度与基准直径位置等组合。
   注意：避免用过多相互推导尺寸造成过约束和公差冲突。

3. 球面
   使用“S⌀”或“SR”，并标球心位置、截取范围及必要的轮廓要求。

4. 自由曲面
   采用坐标点、截面曲线、理论轮廓加轮廓度、受控CAD数据或专用样板要求。
   注意：必须明确检验依据和数据版本，零散圆弧尺寸通常不足以定义复杂曲面。

5. 偏心结构
   标注偏心距、偏心方向/角向位置、相关直径和轴向位置。
   注意：区分“轴线间距”和“径向跳动”；两者不是同一个要求。
