# 板类零件

分类特征：
1. 厚度明显小于长度和宽度。
2. 主要特征分布在一个或两个大平面上。
3. 常见孔组、槽口、缺口和外轮廓加工。

推荐视图：
1. 显示最大轮廓和全部孔位的正视图。
2. 表示厚度的侧视图或直接采用“t”标注。
3. 沉孔、锪孔、台阶孔和斜孔增加剖视图。
4. 异形边缘或小特征可用局部视图、局部放大图。

必须检查的几何尺寸：
1. 总长、总宽和厚度。
2. 外轮廓的直线段、圆弧、斜边和角度。
3. 圆角、倒角、缺口和切口。
4. 安装孔的孔径、数量、孔距和定位尺寸。
5. 长圆孔的宽度、长度或两圆心距及位置。
6. 沉孔、锪孔、螺纹孔的规格和深度。
7. 孔组相对基准边、基准面或中心线的位置。
8. 槽、凹台和沉台的长度、宽度、深度及位置。


标注注意事项：
1. 中心对称孔组优先标孔距和中心对称关系。
2. 不同时标注孔距、两端边距和总长而形成重复或封闭尺寸链。
