# 箱体与壳体类零件

典型零件：
减速器箱体、泵体、阀体、轴承箱、机座、复杂壳体。

分类特征：
1. 具有内部腔体、壁厚、凸台、筋板和多个加工面。
2. 常具有多个相互关联的孔系和安装面。
3. 通常由铸造或焊接毛坯再进行机械加工。

推荐视图：
1. 主视图、俯视图和必要的侧视图。
2. 通过主要孔系的全剖、半剖或阶梯剖视图。
3. 腔体、油道和局部结构采用局部剖视。
4. 小孔、密封槽和局部凸台采用局部放大图。

必须检查的几何尺寸：
1. 总长、总宽和总高。
2. 安装底面和主要加工面的尺寸。
3. 主要孔径、孔深和孔中心高度。
4. 多个轴承孔或轴孔之间的中心距。
5. 孔系相对安装基准的位置。
6. 法兰面、端面、凸台和沉台的厚度与位置。
7. 腔体尺寸、开口尺寸和壁厚。
8. 加强筋、耳板和支承结构尺寸。
9. 安装孔、定位销孔、螺纹孔的规格、数量和位置。
10. 油孔、油槽、放油孔的尺寸、位置及连通关系。
11. 密封槽、止口和轴承挡肩尺寸。
12. 铸造圆角和拔模斜度；只在有设计依据时确定。

推荐基准思路：
1. A基准：主要安装底面或主要结合面。
2. B基准：主要轴承孔轴线或中心平面。
3. C基准：端面、侧面、定位销孔或次要轴线。
4. 最终基准必须与实际加工、装配和检验方案一致。

有设计依据时检查的精度项目：
1. 安装底面的平面度。
2. 主要孔轴线对安装面的平行度。
3. 同轴孔之间的同轴度。
4. 平行轴孔之间的平行度和中心距公差。
5. 端面对主要孔轴线的垂直度。
6. 定位销孔和螺栓孔组的位置度。
7. 密封面的平面度和粗糙度。

标注注意事项：
1. 不能只标外形尺寸，必须完整表达主要孔系、中心高度、中心距和安装基准。
2. 毛坯尺寸和加工面尺寸宜分组标注，并建立明确联系。
