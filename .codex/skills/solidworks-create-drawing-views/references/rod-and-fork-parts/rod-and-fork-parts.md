# 杆件与叉架类零件

典型零件：
连杆、拉杆、推杆、拨叉、叉架、摇臂、摆臂、曲柄。

分类特征：
1. 通常有两个或多个主要连接孔。
2. 主要功能尺寸往往是孔中心距、叉口宽度或运动偏置量。
3. 外形可能不规则，但存在明确受力和运动方向。

推荐视图：
1. 清楚表达主要孔中心距和杆身形状的主视图。
2. 侧视图表达厚度、叉口和偏置。
3. 叉口、孔和局部截面可增加剖视或断面图。
4. 复杂过渡区域可使用局部放大图。

必须检查的几何尺寸：
1. 主要孔直径和孔深。
2. 主要孔之间的中心距。
3. 孔相对杆身中心线或中心平面的位置。
4. 杆身宽度、厚度和截面尺寸。
5. 大端、小端和耳板的外形尺寸。
6. 叉口宽度、叉臂厚度和槽深。
7. 结构偏置量。
8. 销孔、螺纹孔的规格和位置。
9. 总长、总宽、总厚。
10. 圆角、倒角和过渡曲线。

有设计依据时检查的精度项目：
1. 两主要孔的中心距公差。
2. 两孔轴线的平行度。
3. 孔相对杆件中心平面的对称度或位置度。
4. 叉臂内侧面的平行度。
5. 叉口宽度公差。
6. 销孔的位置度。
7. 受力过渡圆角和孔表面的粗糙度。
