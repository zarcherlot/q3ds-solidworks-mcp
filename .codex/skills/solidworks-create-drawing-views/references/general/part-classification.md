# 零件分类判断方法


1. 是否具有长轴线且长度明显大于直径？是：优先判断为轴类。
2. 是否为短回转体，并有圆周孔组、中心孔或止口？是：优先判断为法兰、盘盖类。
3. 是否以内外同轴圆柱面和通孔为主？是：优先判断为套筒类。
4. 是否厚度远小于长宽且特征主要分布在平面内？是：优先判断为板类。
5. 是否具有内部腔体、复杂孔系和多个加工面？是：优先判断为箱体、壳体类。
6. 是否具有安装底面、承载孔、立板和筋板？是：优先判断为支架、座体类。
7. 是否以孔中心距、叉口或运动连接结构为主要功能？是：优先判断为杆件、叉架、拨动类。
8. 是否具有齿形、带槽、链齿或凸轮轮廓？是：优先判断为传动零件。
9. 是否属于标准螺纹、销、键、卡环连接结构？是：优先判断为紧固与连接件。
10. 若同时符合多个类别，选加工和标注特征最突出的类别作为主类别，其他类别作为次类别标签。
