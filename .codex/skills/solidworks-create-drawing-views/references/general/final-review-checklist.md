# 最终修改与审核检查

1：三维模型与二维图的一致性
  1.1工程图关联到正确零件、正确配置、正确显示状态和正确材料。
  1.2 模型及图纸强制重建无错误、无悬空尺寸、无丢失引用。
  1.3视图轮廓与模型一致，孔数、槽数、阵列、镜像特征和抑制状态无遗漏。
  1.4二维尺寸与模型驱动尺寸/PMI一致；覆盖显示值的尺寸均有理由并经批准。
  1.5剖视、局部剖和断面来自当前模型。
可采用“模型测量对照”，但测量值只用于发现二维/三维不一致，不能在缺少设计依据时自行补定公差。


2：视图、投影、剖视和图线
  2.1主视图选择最能表达主要形状、工作位置或主要加工位置的方向。
  2.2视图数量“足够但不冗余”，能唯一表达内外结构。
  2.3 基本视图保持正确投影关系和对齐；自由配置的向视图标明方向和名称。
  2.4局部视图、斜视图、放大图具有清楚的范围、编号和比例。
  2.5剖切位置穿过需要揭示的孔、槽、腔和对称面；箭头方向、字母和剖视名称对应。
  2.6 全剖、半剖、局部剖、阶梯剖或旋转剖的选择恰当，不产生虚假轮廓。
  2.7剖面线方向、间距一致，不掩盖尺寸和轮廓；纵向剖到肋、轮辐、薄壁等时按规则处理。
  2.8可见轮廓、不可见轮廓、中心线、对称线、尺寸线、剖切线、断裂线线型正确。
  2.9孔、轴、回转面和对称结构有必要的中心线/中心标记，且中心线适当超出轮廓。
  2.10 相贯线、过渡线、螺纹、花键、齿轮、弹簧等按适用标准表达。
  2.11等轴测图仅用于辅助理解；不得用等轴测图替代必要的正投影尺寸表达。
  2.12不依靠颜色作为唯一的信息载体，因为打印、复印或转换后颜色可能丢失。


3： 尺寸完整性、唯一性和可读性    对每个特征分别检查“定形、定位、总体”三类尺寸：
  3.1所有制造所需特征均有定形尺寸：直径、半径、宽度、深度、角度、锥度、倒角、圆角、厚度等。
  3.2所有特征相对功能/工艺基准均有明确定位尺寸。
  3.3总长、总宽、总高或包络尺寸完整且不与局部尺寸矛盾。
  3.4每个尺寸通常只出现一次，并放在最清楚的视图。
  3.5关键功能、配合和安装尺寸为直接尺寸，不依赖多级计算得到。
  3.6避免无意形成封闭尺寸链；必须封闭时明确哪个尺寸为参考、理论正确或受控尺寸。
  3.7尺寸链的基准和公差分配能保证最坏情况下的功能要求；必要时进行公差叠加分析。
  3.8尺寸不标在不可见轮廓上；尺寸界线、尺寸线、箭头和文字没有歧义。
  3.9平行尺寸按“小尺寸靠内、大尺寸靠外”排布，交叉和重叠尽量少。
  3.10直径、半径、球面、方形、厚度、弧长等符号使用正确。
  3.11孔组完整标明孔径、数量、深度/通孔、沉孔/锪孔、孔距、分布圆和相对基准位置。
  3.12对称孔组优先通过中心线、孔距或基本尺寸表达，不重复标注可由总体尺寸推导的两端边距。
  3.13 槽和键槽明确宽度、深度、端部形状、长度和位置；不能只给轮廓看起来“差不多”的尺寸。
  3.14倒角明确形式（如C、角度×长度），避免“所有锐边倒钝”与局部精确倒角冲突。
  3.15重复特征只有在形状、尺寸和要求完全相同时才能用“n×”或统一说明。
  3.16参考尺寸清楚标识，且不被用于验收；理论正确尺寸与位置/轮廓度框格配套使用。
  3.17单位明确；同一图若混用mm、inch或角度单位，必须在相应位置清晰标出。
  3.18小数位数和公差表达符合企业规则，不以多余小数位制造虚假精度。
  3.19任何尺寸均不得仅通过按比例量图获得。
强制做一次“逐特征覆盖检查”：把模型中的每个面、孔、槽、台阶、螺纹、倒角和圆角按顺序编号，确认它至少有一个制造定义，并能在检验特性表中找到对应项。



4：孔、螺纹和标准结构
  4.1普通孔注明直径、数量、通孔或深度；盲孔区分有效圆柱深度、钻尖深度或总深度。
  4.2沉孔、锪孔、沉头孔注明大径、深度或角度，并指明与哪个孔同轴。
  4.3螺纹注明标准体系、规格、公差带/精度等级、旋向、有效长度/深度和数量。
  4.4内外螺纹退刀槽、倒角、螺纹不完整段、最小完整牙长度满足装配及加工。
  4.5管螺纹、锥螺纹、密封螺纹明确标准，不只写公称直径。
  4.6 销孔、铰孔、定位孔的加工顺序、配作/组合加工要求和检验状态明确。
  4.7键槽、花键、齿轮、滚花、中心孔等引用适用标准并给出必要参数。
  4.8标准件接口与实际采购规格一致，避免使用“名义相同但系列不同”的螺纹或沉头角。
