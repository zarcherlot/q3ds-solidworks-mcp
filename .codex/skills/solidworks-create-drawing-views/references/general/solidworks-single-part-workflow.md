## 1. 自动化边界

仅使用 SolidWorks 原生 COM API、宏接口或等效原生自动化接口。允许调用的操作范围包括：

- 启动或连接 SolidWorks，打开和重建零件；
- 读取文档类型、配置、显示状态、自定义属性、材料、尺寸、PMI 和几何；
- 从模板新建工程图并建立模型视图；
- 创建投影视图、剖视、断面、局部视图、斜视和放大图；
- 建立或保持投影对齐、中心线、中心标记及模型关联；
- 导入、创建、隐藏、删除或移动工程图尺寸和注释；
- 读取图纸、图框、视图、尺寸与注释的实际坐标和显示包围框；
- 填写属性驱动标题栏、保存 `.SLDDRW` 并导出 PDF、DWG 或 DXF。

禁止以远程桌面、鼠标、键盘、屏幕坐标、截图识别或图像识别执行上述写操作。导出后的渲染只用于只读检查。

## 2. 输入与状态记录

在创建工程图前记录：

- 输入文件绝对路径、文档类型和 SolidWorks 版本；
- 零件配置、显示状态、单位、材料和自定义属性；
- 重建结果及错误或警告；
- 模型中可用的设计尺寸、PMI、基准、形位公差、粗糙度和其他制造属性；
- 用户提供的项目标准、图号、版本和导出格式；
- 使用的上海加速纪元模板、图纸格式和图幅。

任何模型配置、材料或版本不明确时，在继续前将其列为阻塞或待确认项，不要自行选择会改变制造含义的替代值。

## 3. 建图与关联

1. 从上海加速纪元模板新建工程图。
2. 以指定零件、配置和显示状态建立主视图。
3. 从主视图创建基本投影视图，不要用独立模型视图模拟俯视、左视或右视。
4. 依据类别规则和特征清单创建所需剖视、断面、局部、斜视和放大图。
5. 为回转、孔系和对称特征创建原生中心线或中心标记。
6. 设置视图比例、显示样式、隐藏线和切线边；非图纸主比例视图单独标比例。
7. 在每次移动视图后确认投影对齐和模型引用仍有效。

## 4. 尺寸与制造信息来源

按以下优先级使用信息：

1. 模型驱动尺寸、PMI、配置属性和已批准设计数据；
2. 用户明确提供的受控标准、计算文件或设计要求；
3. 当前实体几何测量值，仅限模型无可导入尺寸或 PMI 时的参考标注。

不得将第 3 级数据提升为正式制造要求。不得从导出图片、屏幕像素或按图比例测量制造尺寸。

为每个标注保留可追溯信息：目标特征、尺寸类型、来源、所处视图、是否驱动、是否仅供参考。覆盖模型显示值时必须记录理由和批准依据。

## 5. 包围框与排版检查

### 检查对象

逐项获取以下对象的实际显示包围框：

- 尺寸数值、前后缀、公差和符号；
- 箭头、尺寸线和尺寸界线；
- 孔标注和数量/深度文字；
- 基准、形位公差、粗糙度和焊接等符号；
- 引出注释、技术要求和材料说明；
- 标题栏中文、英文、图号、版本及其他字段。

如果一个 API 对象只返回插入点或锚点，不得将其当作包围框。应使用能反映实际显示边界的原生接口；若某类对象无法获得可靠显示边界，则该项不能宣告检查合格。

### 四边判定

以图框有效内边界为 `left`、`right`、`bottom`、`top`。左边界是装订边之后的有效图框线，不是纸张左边缘。对对象包围框 `xmin`、`xmax`、`ymin`、`ymax` 和安全间距 `margin` 检查：

- `xmin >= left + margin`
- `xmax <= right - margin`
- `ymin >= bottom + margin`
- `ymax <= top - margin`

`margin` 不小于当前对象的一个字高。还要检查对象包围框之间，以及对象与视图轮廓之间的重叠、压线和遮挡。

### 修正顺序

优先移动尺寸或注释，其次移动不破坏投影关系的视图，再调整局部比例或图纸主比例，最后换用更大图幅。不要把字号缩小到不可读，也不要容忍内容压线或越框。

## 6. 重建、导出和只读复核

1. 在尺寸整理、标题栏填写和最终排版后强制重建。
2. 检查模型引用、配置、显示状态、悬空尺寸、丢失引用和视图错误。
3. 运行完整审核清单及逐特征覆盖检查。
4. 保存 `.SLDDRW`。
5. 通过原生接口导出要求的 PDF、DWG 或 DXF。
6. 渲染全部导出页面，只读检查文字、字体、箭头、尺寸线、引出线、视图和标题栏是否缺失、遮挡、越界或异常。
7. 发现问题时返回 `.SLDDRW`，通过原生接口修正并重新执行重建、包围框检查和导出。

不得直接编辑导出文件作为修复手段。

## 7. 失败与阻塞处理

遇到以下情况立即停止相应阶段并报告：

- SolidWorks 原生接口不可用、无响应或被模态对话框阻塞；
- 输入不是单零件 `.SLDPRT`，或模型无法重建；
- 指定配置、显示状态、模板或图纸格式不存在；
- 无法确定正确模型版本、材料、图号或其他会改变制造含义的数据；
- 必需制造要求没有受控来源；
- 无法可靠获取关键对象的实际显示包围框；
- 导出或渲染不完整，无法完成全页复核。

报告中区分：已完成、未完成、未验证、阻塞原因、需要的输入。不得在阻塞后改用 UI 自动化或把未验证输出标记为合格。
