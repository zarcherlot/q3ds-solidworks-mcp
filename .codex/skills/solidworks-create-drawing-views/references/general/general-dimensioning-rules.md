# 通用尺寸标注规则

通用类标注事项：
1. 图纸必须完整表达制造、装配和检验所需的信息。
2. 图上尺寸数值表示实际成品尺寸，不受图纸比例或绘制误差影响。默认单位为 mm，使用其他单位必须写明。
3. 同一尺寸只标注一次，并放在表达最清楚的视图中。尺寸数字、箭头大小和字高在同图中一致；尺寸线不能代替其他图线，也不应与其他图线重合。
4. 尺寸分为定形尺寸、定位尺寸和总体尺寸，尺寸基准可以是点、线、面，三类均需检查。三类尺寸应完整，但不能重复。
5. 尺寸应从可加工、可装配、可检验的基准引出，避免在相贯线、不可见轮廓线上标尺寸。不要从毛刺边、非功能圆角、模糊相贯线或难以测量的虚拟边引出关键尺寸。
6. 小尺寸靠近图形，大尺寸依次向外布置，避免尺寸线交叉、压线和越框。同一加工方法或同一特征的尺寸集中布置。
7.角度尺寸界线沿径向引出、尺寸线为以角顶点为圆心的圆弧，数字水平写。对称件只画半边时，尺寸线稍超越中心线/断裂边界，箭头置一端。
8. 直径用“⌀”，半径用“R”，球面用“S⌀”或“SR”，方形用“□”，板厚可用“t”。弧长数字上方加弧长符号,整圆或大于半圆的圆形尺寸通常用直径，小于或等于半圆的圆弧通常用半径。空间不足时用引出线、外置箭头或局部放大，不要牺牲可读性。
9. 中文主体文字使用模板中的宋体（SimSun）；工程尺寸中的数字和字母使用“上海加速纪元图框”模板中的 Century Gothic；其他文字保持模板原有字体。
10. 对零件上重复出现且尺寸、形式及技术要求完全相同的圆角和倒角，避免在视图中逐处重复标注引导线和数值，采用技术要求统一文字说明的方式标注。对于尺寸不同、功能相关、影响装配或需要重点检验的圆角和倒角，仍应在相应视图中单独标注。
11. 合理布置尺寸线、尺寸界线和尺寸文字，尽量避免其与视图轮廓线或其他标注发生多处交叉、重合。尺寸数值原则上应布置在尺寸线的中间位置；在不发生重叠的前提下，尽量避免将尺寸文字引至尺寸线外部。
12. 自动优化标注字体大小。在保证标注清晰、易读且互不重叠的前提下，字体应尽可能放大。
13. 尺寸文字置于两条尺寸界线之间，尺寸线保持直线，禁止折线、转折引线及文字放在测量区间外。完成后渲染 PDF，检查尺寸、箭头、文字、注释和标题栏无重叠、压线或越框，发现问题须自动调整并重新导出，确认无误后再交付。

三维模型信息的使用边界：
1. 可直接读取或测量：长度、直径、厚度、孔径、孔距、槽宽、深度、角度、圆角、倒角等几何信息。
2. 必须读取模型PMI、属性、设计文件或由用户确认：尺寸公差、配合、基准、形位公差、粗糙度、材料状态、热处理、硬度、涂层和其他制造要求。
3. 模型没有尺寸或PMI时，只能把实体测量值作为待确认的参考标注，并在图纸中统一注明：“图中尺寸均为当前三维实体测量数值，待确认。”
4. 不得在每个测量尺寸后单独追加“REF”“参考”或“待确认”。

完整零件图内容包含：
1.完整零件图包括：表达零件内外结构的视图、制造检验所需全部尺寸、技术要求和标题栏。
2.选择粗糙度时以功能和工艺为据：满足功能前提下取尽可能大的 Ra 值；工作表面、配合面、承受循环载荷或应力集中位置通常需更小 Ra。相同要求可按标准进行统一标注；不要把未确认的值写入图纸。
3.配合可分间隙、过盈、过渡；装配图表达孔/轴配合代号，零件图按生产需要标公差带代号、偏差数值或两者。公差等级、基孔/基轴制须由设计要求或现有标准确定。
4. 在图框内的空白区域添加模板中已有的技术要求，必须保持原文，不得自行改写、增删或编造。若有重复出现尺寸、形式及技术要求完全相同的圆角和倒角，技术要求中加入统一说明例如：未注圆角均为 R2。未注倒角均为 C1。
5. 材料信息必须从三维模型属性中读取，并填写在右下角标题栏中 EUV-P 左侧的空格内，材料中文名称填写在 EUV-P 下方；材料英文编码填写在中文名称下方。
