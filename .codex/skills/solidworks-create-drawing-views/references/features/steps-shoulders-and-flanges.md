# 台阶、轴肩与法兰层级标注


需要标注：
1. 每一级直径或宽度。
2. 每一级轴向长度、高度或深度。
3. 相邻级之间的圆角、倒角或退刀结构。
4. 配合段的尺寸公差、圆柱度、同轴度/跳动和粗糙度。
5. 端面相对基准轴线的垂直度或端面跳动（需要时）。

注意事项：
1. 同轴多级直径集中标在轴向剖视图或非圆视图中，小直径靠近轮廓、大直径向外排列。
2. 轴向尺寸尽量从共同端面基准标注关键台阶位置，避免连续链式标注造成累积误差。
3. 止口必须同时具备直径、轴向高度和相对基准的同轴/跳动要求（若功能需要且有依据）。
4. 法兰圆形视图主要表达孔组、分布圆和径向槽；外径、内孔、台阶孔和轴向长度宜集中到轴向剖视图。
