# 钣金特征标注

1. 板厚
   标注材料厚度t及其适用范围。

2. 折弯
   标注折弯角度、内弯半径、折弯方向、折弯线位置及成形后的关键边长/高度。

3. 翻边、卷边和压筋
   标注高度/直径、宽度、半径、角度、位置和方向。

4. 冲孔、切口和百叶孔
   标注开口尺寸、方向、数量、间距及相对基准位置。

注意事项：
1. 必须明确尺寸是成形后尺寸、展开尺寸、理论尖角尺寸还是切点尺寸。
2. 折弯扣除、K因子、展开长度和回弹补偿应来自企业工艺或已批准模型，不可凭经验写入正式图纸。
3. 关键装配尺寸优先标成形后尺寸；展开图用于下料时要与成形图保持版本和方向一致。
4. 孔靠近折弯区时，应确认孔到折弯线距离及变形风险，但不得自行更改设计尺寸。
