# 孔组与阵列标注

需要标注：
1. 单个特征的大小。
2. 数量，例如“6×⌀8”。
3. 阵列方式：直线、矩形、圆周、镜像或不等距分布。
4. 孔距、行距、列距或分布圆直径。
5. 阵列整体相对基准的位置。
6. 圆周阵列的起始角、对称方向或角向基准。

推荐表达：
1. 圆周均布孔组：“n×⌀d 均布于⌀D”。
2. 直线等距孔组：数量、孔径、相邻中心距，并给出首孔/孔组相对基准的位置。
3. 矩形孔组：行数×列数、横向孔距、纵向孔距和孔组基准定位。

注意事项：
1. 中心对称孔组优先标孔距和相对中心线的对称关系，不重复标两端派生边距。
2. “均布”只说明角间距相等，若整体需要特定旋转方向，还必须标起始角或与基准中心线的夹角。
3. 位置度采用基准控制时，理论正确尺寸与公差框格应配套，不要再给相互冲突的正负定位公差。
