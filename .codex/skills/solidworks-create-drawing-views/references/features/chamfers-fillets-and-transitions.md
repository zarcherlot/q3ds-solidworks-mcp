# 倒角、圆角与过渡圆弧标注



1. 45°倒角
   可按项目规范使用“C尺寸”，例如C1；多个相同倒角可写“4×C1”或在技术要求中统一说明。

2. 非45°倒角
   标注倒角线性尺寸和角度，例如“2×30°”，并明确引出线指向实际倒角边。

3. 圆角
   标注“R尺寸”；多个完全相同的圆角可标数量或统一写入技术要求。

注意事项：
1. 只有尺寸、形式和技术要求完全相同的重复圆角/倒角才能统一说明。
2. 配合、密封、应力集中或需要重点检验的位置应单独标注，不能被“未注圆角/倒角”覆盖。
3. 不要从理论尖角、圆角切点或倒角边引出无定义的定位尺寸；若必须采用理论交点，应按标准明确表达。
4. “去毛刺”“锐边倒钝”和具体C值含义不同，不要互相代替。
