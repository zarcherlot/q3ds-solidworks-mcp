# 槽与凹腔标注



1. 直槽/开口槽
   标注内容：槽宽、槽长、槽深、端部形状、开口方向和相对基准位置。
   注意：槽宽通常是配合或刀具控制尺寸，应直接标注；槽深应明确从哪个表面测量。

2. 键槽
   标注内容：槽宽、槽深、有效长度、端部形式及相对轴线/端面的轴向和角向位置。
   注意：轴键槽和孔键槽的槽深测量基准不同，应按适用标准和检验方式表达；不要只标从外圆到槽底而让实际槽深含义不清。

3. 环槽和密封槽
   标注内容：槽径或槽底直径、槽宽、槽深、轴向位置、槽底圆角/倒角和必要的粗糙度。
   注意：密封槽尺寸、公差和表面要求必须来自密封件规格或设计文件，不可估算。

4. 退刀槽、越程槽
   标注内容：标准槽型代号或槽宽、槽深/槽径、圆角和位置。
   注意：若采用标准槽型，优先引用明确标准和规格；必须保证刀具退出空间，与相邻配合面尺寸不冲突。

5. T形槽、燕尾槽
   标注内容：槽口宽度、底部宽度、深度、角度、圆角和中心位置。
   注意：通常需要断面图显示实形；角度、宽度和深度要与可用量具及刀具匹配。

6. 口袋、凹腔
   标注内容：轮廓长宽、深度、底部/侧壁圆角、拔模斜度（如有）和位置。
   注意：区分腔底深度与局部台阶深度；复杂腔体可用分层剖视或局部放大，避免大量引线跨越主体。
