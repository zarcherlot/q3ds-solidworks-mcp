# 孔的标注

每个孔或孔组通常必须完整标注：
1. 孔径或螺纹规格。
2. 数量。
3. 深度或“通孔”说明。
4. 孔间距、分布方式和角向起始位置。
5. 孔组相对设计基准的定位尺寸。
6. 必要的尺寸公差、配合、位置度、垂直度或同轴度。
7. 必要的孔口倒角、沉孔、端面锪平和表面粗糙度。

孔标注的共同注意事项：
1. 圆形视图能清楚表达孔的位置和数量时，孔径、孔组和分布圆宜在圆形视图中标注；同轴多级孔在圆形视图中难以辨认时，改在剖视图中标注。
2. 单孔要有孔径和相对基准的定位尺寸；孔组还要有数量、孔距/分布圆及孔组整体定位。
3. 不能用板长、总宽等无关尺寸代替孔中心的定位尺寸。
4. 盲孔要区分圆柱孔深度与钻尖深度。没有特别说明时，不应擅自把钻尖计入有效孔深。
5. 孔轴线方向不直观时，应通过剖视、向视或角度尺寸表达。
6. 孔位置优先从基准面、中心线或中心平面定位，不要从不稳定的外圆切线或圆角边定位。

不同孔型的具体标注
1. 普通通孔
   标注内容：数量、孔径、“通”或等效通孔表达、孔中心位置。
   示例：4×⌀10 通。
   注意：即使是通孔，也不能遗漏孔组相对基准的位置。

2. 普通盲孔
   标注内容：数量、孔径、圆柱孔有效深度和孔中心位置。
   示例：2×⌀8 深15。
   注意：若底部形状影响功能，应另行说明平底、锥底或钻尖角；不要默认平底。

3. 沉孔或阶梯孔
   标注内容：小孔直径与深度/通孔状态、大孔直径与深度、同轴关系和孔位置。
   示例：⌀9 通，沉孔⌀15 深6。
   注意：明确深度从哪个端面测量；多级孔的各级直径和轴向深度应在剖视图中对应清楚。

4. 沉头孔
   标注内容：底孔直径、沉头大径或沉头深度、沉头夹角、数量和位置。
   示例：4×⌀6.6 通，沉头⌀12×90°。
   注意：沉头尺寸应与所用紧固件及装配要求一致，不能只画锥面而不标角度或大径。

5. 锪平孔/端面锪平
   标注内容：底孔、锪平直径、锪平深度或加工至净面、数量和位置。
   注意：锪平面若用于螺栓头或垫圈支承，应根据功能要求控制平面度、垂直度或粗糙度，但必须有设计依据。

6. 螺纹孔
   标注内容：螺纹规格、公称直径、螺距（非默认粗牙时必须写）、公差带、有效螺纹深度或“通”、底孔深度、数量和位置。
   示例形式：M10×1.25-6H 深15，底孔深18。
   注意：
   （1）盲螺纹孔要分别表达有效螺纹深度和底孔深度。
   （2）入口倒角如有专门要求应标注。
   （3）左旋、多线、锥管螺纹等特殊信息必须明确。
   （4）不能未经设计确认自行采用6H、6g等公差带。

7. 铰孔、定位销孔和精密配合孔
   标注内容：孔径、公差带或极限偏差、深度/通孔状态、位置、数量和必要的粗糙度。
   注意：定位孔通常还需位置度、垂直度或孔组基准关系；关键孔距应直接标注，不能由普通尺寸链推算。

8. 锥孔
   标注内容：大端/小端直径、锥角或锥度、有效长度/深度、基准端和位置。
   注意：锥度、角度和端部直径之间不要形成矛盾的过约束；选择与加工和检验方式一致的控制组合。

9. 斜孔和交叉孔
   标注内容：孔径、深度/通孔状态、入口中心位置、轴线角度、交汇位置及必要的剖视。
   注意：必须能唯一确定空间方向；仅在一个投影视图标角度往往不够，应同时给出另一方向的定位或采用辅助视图。

10. 长圆孔
    标注内容：槽宽、总长或两端圆心距、端部圆弧形式、数量和中心线位置。
    注意：若端部为标准半圆，槽宽与端部半径存在确定关系，不要无意重复标成封闭尺寸；应明确采用总长还是中心距作为主要控制尺寸。
