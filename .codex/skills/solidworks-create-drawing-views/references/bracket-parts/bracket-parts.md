# 支架与座体类零件


典型零件：
托架、轴承座、电机座、法兰座、导轨座、支承座。

分类特征：
1. 具有明确安装底面和支承结构。
2. 常包含安装孔、支承孔、耳板、立板、凸台和筋板。

推荐视图：
1. 突出安装面和主要承载孔的主视图。
2. 俯视图表达底面轮廓和安装孔。
3. 侧视图表达中心高度、厚度或偏置。
4. 主要孔、槽和内部结构需要时作剖视。

必须检查的几何尺寸：
1. 安装底面的长度、宽度和厚度。
2. 总高、总宽和总长。
3. 主要支承孔直径和深度。
4. 孔轴线到安装面的中心高度。
5. 孔轴线到侧基准或端基准的位置。
6. 安装孔的孔径、数量、孔距和定位尺寸。
7. 定位销孔的孔径和位置。
8. 槽口宽度、深度和位置。
9. 凸台、耳板、立板和加强筋尺寸。
10. 斜面角度、圆角和倒角。

有设计依据时检查的精度项目：
1. 安装底面平面度。
2. 主孔轴线对安装底面的平行度。
3. 主孔轴线对侧基准面的垂直度。
4. 主孔与定位孔的位置关系。
5. 安装孔和定位孔的位置度。
6. 两支承面之间的平行度。
7. 主安装面和支承孔的粗糙度。
