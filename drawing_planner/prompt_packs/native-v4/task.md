1. 基于 geometry report 与六张标准视图确定主类别、显著次类别、主轴/主平面、工作或安装方向，以及所有必须表达的外部、内部和局部特征。
2. 为每个特征建立表达需求，区分轮廓真形、开口/数量、内部层级、截面真形、空间方向、对称/阵列关系和局部可辨识性。
3. 比较有证据支持的主方向，选择一个主视图；随后只保留通过省略检验的基本投影视图、剖视、断面、局部剖、详图或辅助视图。
4. 为全部视图填写可追溯的模型证据、覆盖关系、冻结选择几何、父子关系、投影对齐、比例依据和布局依据；需要时规划中心标记、对称中心线及标签。
5. 根据图纸 safe zone、reserved zones、投影法和图纸比例完成无碰撞布局，并保留合同要求的 dimension zones。
6. 自检最小性与完整性：每个显著特征均有满足其表达模式的视图，每个最终视图均有不可由其他视图替代的省略影响，不存在仅用于装饰或重复表达的视图。
